## Не проверено и что остаётся

1. Качество детекции и время на банковских видео, длинные ролики и конкурентные запросы. Короткий GPU smoke не заменяет benchmark; скрипты для него готовы.
2. Работа LoRA с реальным адаптером. Предусмотрено локальное подключение, обучения не было.
3. Нормативные связи семи категорий: все unverified, никаких фиктивных пунктов. Страница Әділет отдала только требование JavaScript. Нужен анализ актуальных текстов РК командой.
4. Docker build и NVIDIA runtime: Docker отсутствует в PATH этого Mac. Containerfile/Compose подготовлены, но их запуск не подтверждён.
5. Полная GPU-обработка при заблокированной сети: offline-флаги и локальные пути принудительны, однако полный эксперимент без сети ещё нужен.
6. Публичный HTTPS URL, выдача ключа жюри и допустимость собственного GPU-хостинга. Этим агентом датасет на RunPod не загружался. Использован существующий Pod команды; новые платные ресурсы не создавались.
7. Разметка типов/интервалов ещё не получена. Import/schema готовы; отсутствующие категории и интервалы не выдуманы. Temporal IoU и ручная релевантность кадров ещё требуют оценки.

Инфраструктура и интеграция настоящей Qwen работают. Готовность детектора к финальной оценке требует замеров на разрешённых банковских видео и проверки нормативных связей.
